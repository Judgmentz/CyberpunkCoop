# Cyberpunk Coop

Mod cooperativa a 2 giocatori per Cyberpunk 2077 (versione 2.5), basata su [CyberpunkMP](https://github.com/tiltedphoques/CyberpunkMP).

## Scaricare

Prendi lo zip dall'ultima [release](../../releases/latest), estrailo e avvia `CyberpunkCoop.exe`.
Le istruzioni sono in `LEGGIMI.txt` dentro lo zip. Su Linux: `bash installa-linux.sh`.

L'app controlla da sola se c'e' una versione nuova e propone l'aggiornamento.
